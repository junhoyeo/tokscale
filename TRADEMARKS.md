## You may, without asking

- Say that your project or service uses, works with, or is built on Tokscale, when that is true.
- Use the name in plain text to refer to the Tokscale project or tokscale.ai, for example in articles, talks, tutorials, and package lists.
- Show the unmodified logo next to a link to the project or to tokscale.ai.
- Run an unmodified copy of Tokscale under its name for yourself or your own team, when you do not offer it to the public as a service.

## Ask first

- Before you use the name or logo in the name of a product, service, company, domain, or social account.
- Before you use the name or logo in a way that suggests Junho Yeo or Tokscale endorses or runs your product.
- Before you sell merchandise with the name or logo.

## Forks and hosted versions

If you run a modified version of the web app, or offer any version to the public as a service, give it a different name and logo, and say that it is based on Tokscale.

- Yes: "Acme Usage, based on Tokscale"
- No: "Tokscale Cloud", "Tokscale by Acme"
